# AGE — one-page agent reference

**Mission:** Evolve an artifact toward explicitly governed desirable capabilities without assuming its final implementation is known.

**Attractor:** Purpose + capabilities + non-negotiables + tradeoffs + approval authority + progress signals. Keep architecture assumptions separate. The charter can be refined; changes to core commitments need explicit authorization.

**Route work first:** Routine and reversible work → deliver normally. Consequential uncertainty → hypothesis spike. Conflicting progress criteria → attractor review. Stale idea generation → optional immersion transfer, then test normally.

**Spike sequence:** Observation → claim → strongest rival → mechanism → differentiating prediction → falsifier → fair baseline / independent oracle → smallest adequate experiment → frozen evaluator → evidence → scoped verdict → evolution decision.

**Verdict vocabulary:** SUPPORTED, REJECTED, INCONCLUSIVE, INVALID. Implementation health is separate from claim validity or comparative value. Green code can support a failed business or architecture thesis.

**Evolution choices:** Retain, revise, replace, pivot, defer, stop, or escalate. Do not require every failed hypothesis to become weaker. A narrower successor has a new protocol and new evidential status.

**Immersion:** Cross-domain experience creates candidate patterns; it does not prove them. Recast analogies as falsifiable target-domain claims. Whether immersion changes a higher-order process is provisional, not a fact.

**Progress:** Better decisions and capabilities, with lower justified complexity and preserved invariants, compared to real alternatives. Negative evidence can be valuable; unbounded research is not.

**Governance:** Keep evidence and decisions inspectable and versioned; prevent post-result threshold changes; protect human authorization, safety, privacy, and irreversible effects.

**Implementation rule:** Generate only the smallest skills and workflows required by actual triggers. Never generate seven levels, seven agents, or an ontology platform from analogy alone. AGE itself must earn its cost against simpler engineering.
