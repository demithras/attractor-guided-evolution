name: age-loop
description: Checklist for one iteration of the AGE loop (ledger, top uncertainty, hypothesis, frozen test, verdict, consequence, plateau rule). Use when starting or resuming research or improvement work in this project.
---
The procedure in CLAUDE.md is authoritative and works without this skill.
- [ ] Read records/LEDGER.md and the charter; restate attractors and invariants
- [ ] Plateau counter >= 2? then top uncertainty = framing, via records/templates/IMMERSION.md, plus unanalysed data dimensions
- [ ] Re-rank uncertainties (value = impact x uncertainty / cost), include framing ones; set "next top uncertainty"
- [ ] Hypothesis from template: claim, mechanism, predictions, falsifier, rival
- [ ] Smallest test; frozen criterion saved BEFORE running
- [ ] Run; verdict SUPPORTED/REJECTED/INCONCLUSIVE/INVALID with evidence
- [ ] Consequence: retain/revise/replace/pivot/defer/stop/escalate; propose (never make) attractor/invariant changes
- [ ] Update ledger and counter, commit, loop again or write why done
