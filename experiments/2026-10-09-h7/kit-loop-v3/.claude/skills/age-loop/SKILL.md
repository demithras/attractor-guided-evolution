name: age-loop
description: Checklist for one iteration of the AGE loop (ledger, direction vs attempt, ceiling test, attempt iteration, exploitation rule, plateau rule). Use when starting or resuming research or improvement work in this project.
---
The procedure in CLAUDE.md is authoritative and works without this skill.
- [ ] Read records/LEDGER.md and the charter; restate attractors and invariants
- [ ] Supported direction with capture < ~50% of ceiling? then next = "capture more" (>= 3 materially different attempts) before any new direction
- [ ] Plateau counter >= 2? then framing direction via the ledger Immersion section, plus unanalysed data dimensions
- [ ] Re-rank uncertainties; set the next line
- [ ] Direction row: claim, mechanism, rival, prediction, falsifier; frozen criterion saved BEFORE the ceiling/oracle test
- [ ] Attempts: one ledger line each, compare to current best only; a failed attempt never rejects a direction
- [ ] Reject a direction only by ceiling failure or >= 3 different failed attempts
- [ ] Consequence; propose (never make) attractor/invariant changes; update ledger and counter; commit
